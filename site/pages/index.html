04
Operate from the terminal

Deploy the product.
Keep the agent on the team.

Write the operations you allow as routes under /_ops and run them with spfn ops, in the same terminal your coding agent already works in. Each command has its own input schema and authorization rule. No admin dashboard to build first. When operators work outside a terminal, @spfn/mcp serves the same operations as MCP tools.

Read the full guide
01 / BUILD

Domain operations stay in the app

Ops routes call the same repositories and services as the product instead of duplicating business rules.

02 / SECURE

Identity and policy remain explicit

Every command answers only to a scoped, revocable ops token from @spfn/auth. A command the app marks destructive needs --yes.

03 / RUN

Discovered from the running app

spfn ops list reads what the deployed app exposes, and --describe prints each command's usage from the app's own schemas.
